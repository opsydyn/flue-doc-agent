## What is doc-agent?

A Bun monorepo of autonomous agents built on the [Flue framework](https://flueframework.com/)
using [Effect](https://effect.website/) as the core language.

The first agent — **doc-freshness** — detects stale markdown documentation by comparing
git history against the source files each doc references. It scores results by
page-view demand using [One Dollar Stats](https://onedollarstats.com/) analytics, then
writes freshness metadata back to each file's frontmatter.

## Tech stack

| Concern | Tool |
| --- | --- |
| Agent framework | [Flue](https://flueframework.com/) |
| Core language | [Effect](https://effect.website/) (beta) |
| Runtime | [Bun](https://bun.sh/) |
| Model | OpenAI `gpt-4o` |
| Lint + format | [Biome](https://biomejs.dev/) v2 + linteffect |
| Tests | `bun test` + `effect/testing/FastCheck` |
| Page analytics | [One Dollar Stats](https://onedollarstats.com/) |
